# Handelskalkulation (Vorwärts- & Rückwärtskalkulation)

## Worum geht's

Du lernst, wie ein Händler seinen Verkaufspreis berechnet — vom Einkauf beim Lieferanten
bis zum Endpreis für den Kunden. In der Prüfung wirst du sowohl vorwärts (Einkaufspreis →
Verkaufspreis) als auch rückwärts (Verkaufspreis → Einkaufspreis) rechnen müssen.

---

## Erklärung

### Das Kalkulations-Schema

Jeder Händler folgt demselben Schema. Lernt man es einmal auswendig,
lassen sich alle Aufgaben zur Kalkulation lösen:

```
Listeneinkaufspreis (LEP)
  − Liefererrabatt
= Zieleinkaufspreis (ZEP)
  − Liefererskonto
= Bareinkaufspreis (BEP)
  + Bezugskosten (Fracht, Zoll, Verpackung)
= Bezugspreis (= Einstandspreis)
  + Handlungskosten (Miete, Personal, Energie)
= Selbstkosten
  + Gewinn
= Barverkaufspreis
  + Kundenskonto
  + Kundenrabatt
= Nettoverkaufspreis (Netto-VK)
  + Umsatzsteuer (19 %)
= Bruttoverkaufspreis (Brutto-VK)
```

### Die wichtigsten Begriffe

**Listeneinkaufspreis (LEP):** Der Preis aus dem Lieferantenkatalog — vor allen Abzügen.

**Rabatt:** Ein prozentualer Nachlass auf den Listenpreis, den der Lieferant einräumt
(z. B. für Großbestellungen oder langjährige Kunden).

**Skonto:** Ein prozentualer Nachlass für schnelle Zahlung (z. B. „2 % Skonto bei
Zahlung innerhalb von 10 Tagen"). Skonto wird auf den Preis **nach** Rabatt berechnet.

**Bezugskosten:** Transportkosten, Zölle, Verpackung — alles was anfällt, um die
Ware überhaupt ins Lager zu bekommen.

**Bezugspreis / Einstandspreis:** Was die Ware den Händler wirklich kostet, wenn sie
im Lager ankommt.

**Handlungskosten:** Die laufenden Betriebskosten des Händlers (Miete, Gehälter,
Strom). Wird oft als prozentualer Aufschlag angegeben.

**Selbstkosten:** Bezugspreis + Handlungskosten — ohne Gewinn.

**Kundenrabatt:** Der Nachlass, den der Händler seinem Kunden gibt.
**Kundenskonto:** Preisnachlass für schnelle Kundenzahlung.

> Wichtig: Rabatt und Skonto werden **addiert zurückgerechnet**, wenn man vom Netto-VK
> auf den Barverkaufspreis kommt — sie werden beim Kunden als Abzug gewährt,
> müssen also im Listenpreis einkalkuliert sein.

### Rückwärtskalkulation: Vom Preis zurück zum Einkauf

Manchmal gibt die Aufgabe den Endpreis und fragt nach dem Einkaufspreis oder
einem Zwischenwert. Das Schema läuft dann einfach von unten nach oben:

```
Bruttoverkaufspreis ÷ 1,19       = Netto-VK
Netto-VK           × (1 − Rabatt%) = Barverkaufspreis   [÷ (1 − Rabatt%)]
Barverkaufspreis   × (1 − Skonto%) = ...                 [÷ (1 − Skonto%)]
```

---

## Beispiele – Schritt für Schritt

**Vorwärtskalkulation: Laptop, Listenpreis 800 €**

**1. Ausgangsposition**

```
Listeneinkaufspreis (LEP) = 800,00 €
```

Das ist der Preis im Katalog des Lieferanten, bevor irgendwelche Abzüge greifen.

**2. Liefererrabatt abziehen (10 %)**

```
LEP               = 800,00 €
− Rabatt (10 %)   =  80,00 €
= Zieleinkaufspreis = 720,00 €
```

Rabatt = 800 × 0,10 = 80 €. Der Zieleinkaufspreis (ZEP) ist der Preis nach Liefererrabatt.

**3. Liefererskonto abziehen (2 %)**

```
ZEP               = 720,00 €
− Skonto (2 %)    =  14,40 €
= Bareinkaufspreis  = 705,60 €
```

Skonto = 720 × 0,02 = 14,40 €. Skonto wird auf den ZEP (nach Rabatt) berechnet, nicht auf den LEP!

**4. Bezugskosten addieren (30 €)**

```
Bareinkaufspreis  = 705,60 €
+ Bezugskosten    =  30,00 €
= Bezugspreis       = 735,60 €
```

Fracht, Zoll, Verpackung werden addiert. Das ist jetzt der echte Einstandspreis — was der Laptop den Händler kostet, wenn er im Lager steht.

**5. Handlungskosten aufschlagen (15 %)**

```
Bezugspreis       = 735,60 €
+ HK (15 %)       = 110,34 €
= Selbstkosten      = 845,94 €
```

Handlungskosten = 735,60 × 0,15 = 110,34 €. Jetzt sind alle Kosten des Händlers drin. Verkauft er zum Selbstkostenpreis, macht er keinen Verlust — aber auch keinen Gewinn.

**6. Gewinn aufschlagen (20 %)**

```
Selbstkosten      = 845,94 €
+ Gewinn (20 %)   = 169,19 €
= Barverkaufspreis  = 1.015,13 €
```

Gewinn = 845,94 × 0,20 = 169,19 €. Der Barverkaufspreis ist der Preis für Barzahlung ohne weitere Rabatte.

**7. Kundenskonto und Kundenrabatt aufschlagen**

```
Barverkaufspreis  = 1.015,13 €
÷ (1 − 0,02)      = 1.035,85 €  (Skonto-Aufschlag = 20,72 €)
÷ (1 − 0,05)      = 1.090,39 €  (Rabatt-Aufschlag = 54,54 €)
= Netto-VK          = 1.090,39 €
```

Skonto und Rabatt werden dem Kunden als Abzug gewährt — sie müssen also im Verkaufspreis schon einkalkuliert sein. Saubere Methode: den Barverkaufspreis zweimal hintereinander durch (1 − Satz) teilen. Kurz: 1.015,13 ÷ 0,98 ÷ 0,95 = 1.090,39 €. Die Zwischendifferenzen ergeben Skonto- bzw. Rabatt-Aufschlag.

**8. Mehrwertsteuer (19 %) aufschlagen**

```
Netto-VK          = 1.090,39 €
+ USt (19 %)       =   207,17 €
= Brutto-VK         = 1.297,56 €
```

USt = 1.090,39 × 0,19 = 207,17 €. Das ist der finale Bruttopreis, den der Endkunde zahlt.

**Rückwärtskalkulation: Brutto-VK gegeben, Bezugspreis gesucht**

**1. Szenario**

```
Brutto-VK = 595,00 €
USt = 19 %
Kundenrabatt = 5 %
Handlungskosten = 20 %
Gewinn = 10 %
```

Bei der Rückwärtskalkulation kennen wir den Endpreis und rechnen rückwärts bis zum Bezugspreis.

**2. USt herausrechnen**

```
Netto-VK = 595,00 ÷ 1,19
Netto-VK = 500,00 €
```

Brutto ÷ 1,19 ergibt den Netto-VK. Nie 19 % abziehen (= 595 × 0,81), das wäre falsch!

**3. Kundenrabatt herausrechnen**

```
Netto-VK = 500,00 €
Barverkaufspreis = 500,00 × (1 − 0,05)
= 500,00 × 0,95 = 475,00 €
```

Der Netto-VK enthält den Rabatt bereits als Aufschlag. Durch Multiplizieren mit (1 − Rabattsatz) kommen wir auf den Barverkaufspreis.

**4. Selbstkosten bestimmen (Gewinn heraus)**

```
Barverkaufspreis = Selbstkosten × (1 + Gewinnaufschlag)
475,00 = Selbstkosten × 1,10
Selbstkosten = 475,00 ÷ 1,10
Selbstkosten = 431,82 €
```

Der Gewinn ist ein Aufschlag auf die Selbstkosten. Umgekehrt: Barverkaufspreis ÷ (1 + Gewinnprozent) = Selbstkosten.

**5. Bezugspreis bestimmen (Handlungskosten heraus)**

```
Selbstkosten = Bezugspreis × (1 + HK-Satz)
431,82 = Bezugspreis × 1,20
Bezugspreis = 431,82 ÷ 1,20
Bezugspreis = 359,85 €
```

Analog: Die Handlungskosten sind ein Aufschlag auf den Bezugspreis. Rückwärts: Selbstkosten ÷ (1 + HK-Satz) = Bezugspreis.

---

## Typische Fehler

- **Skonto vor oder nach Rabatt?**: Skonto wird auf den Preis **nach** Liefererrabatt
  berechnet (also auf den ZEP). Erst Rabatt abziehen, dann Skonto abziehen.

- **USt herausrechnen — nie einfach abziehen**: Um den Netto-VK aus dem Brutto-VK zu
  berechnen: `Netto = Brutto ÷ 1,19`. NICHT `Brutto × 0,81` — das wäre falsch.
  Beispiel: 119 € brutto → 119 ÷ 1,19 = 100 € netto. 119 × 0,81 = 96,39 € — falsch!

- **Gewinn als Aufschlag auf Selbstkosten, nicht auf Barverkaufspreis**: Der Gewinn
  wird auf die Selbstkosten aufgeschlagen. 20 % Gewinn bedeutet Barpreis = Selbstkosten × 1,20.

- **Schema auswendig lernen**: Das Kalkulationsschema muss in der Aufgabe verfügbar
  sein — entweder auswendig oder direkt aus der Aufgabe ableitbar. Die Reihenfolge
  LEP → ZEP → BEP → Bezugspreis → Selbstkosten → Barpreis → Netto-VK → Brutto-VK
  ist unveränderlich.
