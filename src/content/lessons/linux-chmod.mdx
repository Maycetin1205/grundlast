# Linux-Dateiberechtigungen (chmod, rwx)

## Worum geht's

Du lernst, wie Linux regelt, wer auf Dateien und Ordner zugreifen darf — und wie du
Berechtigungen mit dem `chmod`-Befehl setzt. In der Prüfung wirst du Oktalzahlen wie `755`
oder `644` interpretieren und berechnen müssen.

---

## Erklärung

### Wer darf was? Die drei Gruppen

Linux verwaltet Berechtigungen für drei Gruppen:

| Gruppe | Symbol | Bedeutung |
|---|---|---|
| **Besitzer** (Owner/User) | `u` | Die Person, der die Datei gehört |
| **Gruppe** (Group) | `g` | Alle Benutzer, die derselben Gruppe angehören |
| **Alle anderen** (Others) | `o` | Alle übrigen Benutzer auf dem System |

### Die drei Rechte

| Recht | Symbol | Oktalwert | Bedeutung |
|---|---|---|---|
| **Lesen** | `r` (read) | **4** | Datei öffnen / Verzeichnis auflisten |
| **Schreiben** | `w` (write) | **2** | Datei bearbeiten / Dateien in Verzeichnis anlegen |
| **Ausführen** | `x` (execute) | **1** | Datei als Programm starten / Verzeichnis betreten |

### Oktalschreibweise: So funktioniert die Berechnung

Für jede der drei Gruppen werden die Rechte als Summe angegeben:

```
rwx = 4 + 2 + 1 = 7   (alle Rechte)
rw- = 4 + 2 + 0 = 6   (lesen + schreiben)
r-x = 4 + 0 + 1 = 5   (lesen + ausführen)
r-- = 4 + 0 + 0 = 4   (nur lesen)
--- = 0 + 0 + 0 = 0   (keine Rechte)
```

Das Ergebnis: Eine dreistellige Oktalzahl wie `755` — eine Ziffer pro Gruppe.

### Übersichtstabelle

| Oktal | Binär | Rechte | Bedeutung |
|---|---|---|---|
| 7 | 111 | rwx | Lesen + Schreiben + Ausführen |
| 6 | 110 | rw- | Lesen + Schreiben |
| 5 | 101 | r-x | Lesen + Ausführen |
| 4 | 100 | r-- | Nur Lesen |
| 2 | 010 | -w- | Nur Schreiben (selten) |
| 1 | 001 | --x | Nur Ausführen (selten) |
| 0 | 000 | --- | Keine Rechte |

### Typische Kombinationen in der Praxis

| Kombination | Bedeutung | Typischer Einsatz |
|---|---|---|
| `755` | Besitzer: rwx / Gruppe: r-x / Alle: r-x | Skripte, Programmdateien, Verzeichnisse |
| `644` | Besitzer: rw- / Gruppe: r-- / Alle: r-- | Normale Textdateien, Konfigurationsdateien |
| `700` | Besitzer: rwx / Gruppe: --- / Alle: --- | Private Dateien, SSH-Schlüssel |
| `600` | Besitzer: rw- / Gruppe: --- / Alle: --- | Private Konfigurationsdateien (z. B. `~/.ssh/id_rsa`) |
| `777` | Alle: rwx | Temporäre Verzeichnisse (sicherheitskritisch!) |

## Typische Fehler

- **r, w, x Werte vergessen**: Die Werte sind fest: r=4, w=2, x=1. Diese drei Zahlen
  müssen auswendig bekannt sein — aus ihnen folgt alles andere.

- **Reihenfolge der Gruppen**: Immer Besitzer → Gruppe → Andere. Nie umdrehen.
  `755` bedeutet Besitzer=7, Gruppe=5, Andere=5 — nicht umgekehrt.

- **Oktalziffer ≠ Summe merken**: 7 = rwx (4+2+1), 6 = rw- (4+2), 5 = r-x (4+1),
  4 = r-- (4). Die 3 kommt nie vor (wäre wx = 2+1, ohne Lesen — extrem selten).

- **Ausführen bei Verzeichnissen**: Für ein Verzeichnis bedeutet `x` nicht „ausführen"
  sondern „betreten" (cd). Ohne x darf man nicht in das Verzeichnis wechseln,
  auch wenn man r hat. In Aufgaben relevant bei Aufgaben zu Verzeichnisrechten.
